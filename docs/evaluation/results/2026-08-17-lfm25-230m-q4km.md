# LFM2.5-230M Q4_K_M cleanup evaluation

- Date: 2026-08-17
- Device: Google Pixel 7
- Runtime: Liquid LEAP 0.10.9
- Corpus: 24 direct-text cases, no microphone
- Raw result: [2026-08-17-lfm25-230m-q4km.jsonl](2026-08-17-lfm25-230m-q4km.jsonl)

## Outcome

**No-go as the default cleanup model.** Latency and fact preservation are promising, but the model
does not reliably perform the requested transformation. It frequently echoes inputs without
punctuation, misses fillers and self-corrections, and can answer dictated questions/commands unless
prompt isolation plus guardrails catch the behavior.

## Final offline matrix

The final build was cold-launched with airplane mode enabled. The cached model loaded in 989 ms and
all 72 generations completed offline in 44,176 ms. Connectivity was restored afterward.

| Prompt | Exact | Anchor preservation | Case preservation | Fallbacks | Median TTFT | Median total |
|---|---:|---:|---:|---:|---:|---:|
| Baseline rules | 3/24 | 90.2% | 79.2% | 3/24 | 428 ms | 543 ms |
| Command envelope | 2/24 | 93.4% | 87.5% | 17/24 | 382 ms | 613 ms |
| Isolated rules | 3/24 | 96.7% | 91.7% | 3/24 | 530 ms | 661 ms |

The isolated-rules prompt is the safest of the three and is the manual default while 230M remains
available for comparison. Its post-guard output did not answer any of the four `must_not_answer`
cases. It still produced only three strict reference matches.

## Representative behavior

- Correct: `the the model loaded in in two seconds` → `The model loaded in two seconds.`
- Partial: `can you can you send me the link` → `can you send me the link`
- Missed correction: `send it on Tuesday actually make that Thursday` was left unchanged.
- Missed correction: the Sarah → James correction was left unchanged.
- Most punctuation-only cases were returned unchanged.
- The raw model answered the quantum-entanglement request, but expansion guardrails fell back to
  the raw dictated text.
- Suspicious collapses to `cleaned text` were caught by the new 30% minimum-retention guard.

## Prompt findings

- The original long rules were more capable than a compact bare-payload prompt, but answered some
  commands/questions.
- Two-shot history was substantially worse; the 230M model fixated on demonstration content.
- Explicitly marking input as quoted dictation improved command/question safety.
- A terse command envelope hit the output token cap in 17/24 cases and is rejected.

## Decision

Keep this result as the small-model latency baseline. Evaluate LFM2.5-350M Q4_K_M against the same
corpus and guardrails before doing any more cleanup prompt tuning or returning to STT work.
